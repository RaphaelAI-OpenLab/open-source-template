# Contributing to Raphael AI OpenLab

Thanks for helping make AI creativity more useful and approachable. These defaults apply unless a repository provides more specific instructions.

## Pick a contribution

- Fix a broken instruction or improve an explanation.
- Share an original prompt with a clear creative goal and reusable variables.
- Document a workflow with inputs, settings, steps, limitations, and a way to assess the result.
- Translate an existing resource, keeping links and examples aligned with the source.
- Propose a focused tool or integration in an issue before starting a large implementation.

## Before opening a pull request

1. Search existing issues and pull requests to avoid duplicate work.
2. Read the repository README and license. Fork the repository and create a focused branch.
3. Keep the change small enough to review. Explain the problem, the result, and how you checked it.
4. For Node projects, use **pnpm** and follow the repository's pinned version and lockfile.
5. Follow the project-specific checks. Documentation-only changes need link and rendering checks; do not invent test results.
6. Use the PR checklist. Maintainers may request revisions before merging.

## Prompt and workflow submissions

Include a title, intended use, prompt text, adjustable variables, model/version and settings if actually tested, reference requirements, limitations, and source/license details. Clearly label untested examples. Provide a preview only when you have rights to publish it, and distinguish generated examples from real photographs.

Never claim "works with every model" or report invented sample counts or benchmark results. Do not copy another collection wholesale. Preserve attribution and comply with licenses when adapting material.

## Content and privacy

Submit only material you created or have permission to share. Do not include secrets, private user data, account details, unlicensed images, or misleading impersonations. Avoid uploading sensitive reference photographs. Remove private metadata from examples.

## Language

English is the default for broadly shared project documentation. Chinese contributions and translations are welcome; identify the source document and keep terminology consistent.

## Review and communication

Use repository issues for reproducible bugs and proposals. Use discussions when a repository enables them. Product/account support goes to **support@raphael.app**; security reports follow [SECURITY.md](https://github.com/RaphaelAI-OpenLab/.github/blob/main/SECURITY.md).

By contributing, you agree that your original contribution may be distributed under the receiving repository's stated license. Third-party material must retain its applicable license and attribution.
