# Project brief

Complete this brief before replacing the starter README.

- **Purpose:** What specific user problem or creative goal does this project serve?
- **Audience:** Who will use it, and what do they need to know already?
- **Initial scope:** What does the first working version include?
- **Out of scope:** Which features are intentionally deferred?
- **Inputs and outputs:** What does a user provide and receive?
- **Validation:** How can someone reproduce and assess the result?
- **Dependencies:** Which models, services, versions, or credentials are required?
- **Rights:** What licenses and permissions cover the code, prompts, and assets?
- **Limitations:** What is untested, unreliable, or still planned?

Publish only verified claims in the README. Remove unused placeholders and template instructions before launch.
