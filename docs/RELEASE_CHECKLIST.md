# Release checklist

- [ ] The README describes a working, bounded project and its current status.
- [ ] Setup and examples work in the documented environment.
- [ ] Relevant checks pass and their commands are documented.
- [ ] Model/provider claims list the versions actually tested.
- [ ] No secrets, private account information, customer data, or internal operational files are present.
- [ ] Code, prompts, data, previews, and reference assets have clear licenses and attribution.
- [ ] Security reporting and support links work.
- [ ] The description, topics, website, and repository visibility are correct.
- [ ] Changes and limitations are recorded for the release.
- [ ] Any release artifact can be built from the tagged source and contains only intended files.
