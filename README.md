# Raphael AI Open-Source Starter

A lightweight starting point for open-source prompt collections, creative guides, tools, and integrations from [Raphael AI](https://raphael.app).

**Status:** repository template. It contains documentation and collaboration scaffolding; no runtime, SDK, or API integration is included.

## Use this template

1. Select **Use this template → Create a new repository** on GitHub.
2. Choose `RaphaelAI-OpenLab` as owner, a focused kebab-case project name, and the appropriate visibility.
3. Replace this README with your project's purpose, current status, installation/use instructions, one reproducible example, limitations, and license.
4. Adjust `CONTRIBUTING.md`, the issue forms, and PR checklist for the project. Add only the checks and workflows the project needs.
5. Review [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md) before making a release.

## Included

- MIT license for the original starter material.
- Contribution guide, issue forms, and pull request checklist.
- Project brief and release checklist.
- A minimal `.gitignore` for common local files, secrets, and Node build output.

Security, support, and community guidelines inherit from the organization's [public defaults](https://github.com/RaphaelAI-OpenLab/.github).

## Package manager

For Node projects, use **pnpm**. Pin the actual pnpm version when you introduce a package manifest and commit its lockfile. This starter intentionally has no dependencies or development server.
